How does this work?

This dashboard fetches live data directly from federal APIs and runs a simplified hydrological forecast in your browser:

  1. Observed streamflow — 90 days of daily mean discharge from USGS NWIS
  2. Weather forecast — 7-day gridded temperature & precipitation from the NWS API
  3. Baseflow separation — Lyne-Hollick digital filter with fitted recession constant anchored to current observed flow
  4. Snowmelt model — Degree-day method scaled by effective snow-contributing area fraction
  5. Rainfall-runoff — NRCS/SCS Curve Number method with unit hydrograph convolution
  6. Channel routing — Muskingum method for flood-wave attenuation
  7. Uncertainty — Confidence bands widen from ±15% at day 1 to ±50% at day 14

The full Python implementation (with SNOTEL snowpack integration and more) is available in the GitHub repository.
