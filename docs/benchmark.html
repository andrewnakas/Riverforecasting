How does the benchmark work?

Hindcasting is the standard method for evaluating forecast models. For each test date in the past:

  1. We pretend we're standing on that date, using only data available at the time
  2. We generate a 14-day forecast using all three methods (AR(1), KNN, Climatology) plus the blended model
  3. We compare the forecast against the actual observed flows that followed
  4. We compute standard hydrology metrics (NSE, RMSE, MAE, MAPE, bias, skill scores)

Metrics explained:

  • NSE (Nash-Sutcliffe Efficiency): 1.0 = perfect, 0.0 = no better than using the mean, <0 = worse than the mean
  • Log-NSE: NSE in log-space, reduces influence of high flows
  • MAPE: Mean Absolute Percentage Error — average % deviation
  • % Bias: Systematic over/under prediction. Positive = over-predicts
  • Skill Score vs Climatology: >0 means forecast beats the seasonal average
  • Skill Score vs Persistence: >0 means forecast beats "tomorrow = today"

Results are broken down by site, season, and lead time (day 1-3, 4-7, 8-14) to identify where the model performs best and worst.
